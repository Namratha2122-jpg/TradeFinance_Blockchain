# Trade Finance Blockchain

A web-based trade finance project developed as part of an internship/academic project, focused on organizing trade finance workflows, transactions, documents, risk analysis, and related information through a centralized application interface.

## Overview

Trade Finance Blockchain provides a web interface for managing and viewing different aspects of trade finance operations.

The project includes dedicated components for:

- Trade finance documents
- Transactions
- Risk analysis
- Analytics
- Ledger-related information
- User authentication

## Technology Stack

| Technology | Usage |
|---|---|
| Python | Backend application |
| FastAPI | Web application framework |
| SQLAlchemy | Database interaction |
| HTML | Web pages |
| CSS | Interface styling |
| JavaScript | Client-side functionality |
| Database | Application data storage |

## Main Modules

### Authentication
Provides the application's login and signup interfaces.

### Documents
Handles trade-finance-related document information through the application interface.

### Transactions
Provides functionality for working with transaction-related information.

### Risk Analysis
Provides risk-related information and analysis within the application.

### Analytics
Provides an analytics-oriented view of project data.

### Ledger
Contains the project's ledger-related functionality.

## Application

The project follows a web-application structure with a Python backend and browser-based interface.

```

```
